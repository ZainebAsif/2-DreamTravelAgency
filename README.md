Dream Travel Agency
Project Summary:
This project is a static travel agency website developed as part of an academic assignment.
The website provides travel packages, services, and contact information using HTML and CSS.
Technologies which were used are HTML, CSS and github pages.
Website includes a Home page, a service section providing details of all packages, an about page, a gallery section, and contack page.
